# Workflow Rules

## Git Commit & Push Rule
- Mỗi khi hoàn thành xong một phần nội dung (section / topic) mới trong tài liệu ghi chú hoặc code, hãy tự động thực hiện:
  1. `git add` các file liên quan.
  2. `git commit -m "..."` với thông điệp rõ ràng, mô tả nội dung vừa hoàn thành.
  3. `git push origin main` để đẩy lên remote repository.
