# Auto Git Commit and Push Rule

Mỗi khi hoàn thành xong một phần nội dung (section / topic) mới trong tài liệu ghi chú hoặc code:
1. Tự động stage file: `git add .` (hoặc các file liên quan).
2. Commit với commit message rõ ràng: `git commit -m "docs: complete section <name>"`
3. Push lên remote: `git push origin main`
